# Eigen GPX-tracks toevoegen

Deze map is leeg zolang je niets toevoegt — dat is normaal. De kaart in de
Activiteiten-tab toont dan een indicatieve, vereenvoudigde lijn (voor de
routes waar dat verantwoord is) of een startmarkering + de originele
AllTrails/Wikiloc/Wandelnetwerk-link (voor de rest).

Wil je het échte, exacte tracé op de kaart? Download de GPX bij de
originele link (AllTrails/Wikiloc hebben meestal een "GPX exporteren" of
downloadknop) en zet het bestand hier neer onder de juiste naam. De app
pikt het dan automatisch op bij de eerstvolgende keer laden — geen
code-wijziging nodig.

| Bestandsnaam | Route |
|---|---|
| `kennemerduinen-vogelmeer-kraansvlak.gpx` | Kennemerduinen — Vogelmeer & Kraansvlak |
| `koevlak-parnassia.gpx` | Lange duinhike Koevlak–Parnassia |
| `awd-de-zilk.gpx` | Amsterdamse Waterleidingduinen — ingang De Zilk |
| `strand-bloemendaal-zandvoort.gpx` | Strandwandeling Bloemendaal–Zandvoort v.v. |
| `noordvoort-strandpaal-64.gpx` | Noordvoort & Strandpaal 64 |
| `hofjeswandeling-haarlem.gpx` | Hofjeswandeling Haarlem |
| `amsterdam-noord.gpx` | Amsterdam-Noord wandeling |
| `amsterdam-oost.gpx` | Amsterdam-Oost, minder standaard |
| `duin-haarlem-fiets.gpx` | Duin naar stad → Haarlem (fiets) |
| `bloemendaal-zandvoort-boulevard-fiets.gpx` | Bloemendaal → Zandvoort boulevard (fiets) |
| `buitenplaatsen-tocht.gpx` | Buitenplaatsen-tocht |
| `fort-vijfhuizen.gpx` | Fort bij Vijfhuizen — Stelling van Amsterdam |
| `kraansvlak-stop.gpx` | Kraansvlak-stop |

Een simpel GPX-bestand met `<trkpt lat="…" lon="…">`- of `<rtept>`-punten
volstaat; de app leest dat rechtstreeks in de browser in, er is geen
server of build-stap voor nodig.
